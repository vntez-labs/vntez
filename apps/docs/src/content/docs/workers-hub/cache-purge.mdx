## Mô tả Endpoint

Lập tức xóa bản sao lưu đệm tại toàn bộ các điểm PoP của Cloudflare. Hỗ trợ vô hiệu hóa theo mảng URL hoặc danh mục nhãn phân loại Cache-Tag.

## Dữ liệu Yêu cầu (Request Body)

```json
{
  "tags": ["apps-manifest", "blog-catalog"],
  "urls": ["https://vntez.net/products"]
}
```
