## Mô tả Endpoint

Lập tức xóa bản sao lưu đệm tại toàn bộ hơn 300 điểm PoP của Cloudflare. Hỗ trợ vô hiệu hóa theo mảng đường dẫn URL hoặc danh mục nhãn phân loại Cache-Tag mà không gây gián đoạn lưu lượng truy cập.

## Tham số Yêu cầu (Request Body)

| Tham số | Kiểu dữ liệu | Bắt buộc | Mặc định | Mô tả |
| :--- | :--- | :--- | :--- | :--- |
| `tags` | `string[]` | Tùy chọn | `[]` | Mảng các nhãn phân loại cache (Cache-Tags) cần vô hiệu hóa đồng thời trên toàn bộ các node PoP. |
| `urls` | `string[]` | Tùy chọn | `[]` | Danh sách đường dẫn URL tuyệt đối cần loại bỏ khỏi CDN cache tức thời. |

### Cấu trúc JSON Request Mẫu

```json
{
  "tags": ["apps-manifest", "blog-catalog"],
  "urls": ["https://vntez.net/products"]
}
```

## Phản hồi Thành công (200 OK)

| Trường dữ liệu | Kiểu | Mô tả |
| :--- | :--- | :--- |
| `success` | `boolean` | `true` khi toàn bộ cụm Cloudflare PoP đã tiếp nhận lệnh xóa cache thành công. |
| `purged_items` | `number` | Tổng số bản ghi cache đã được dọn sạch khỏi bộ nhớ biên. |
| `execution_time_ms` | `number` | Thời gian hoàn tất tính bằng mili-giây tại cạnh mạng. |
| `zone_id` | `string` | Mã định danh phân vùng Cloudflare Edge Zone quản lý dịch vụ. |

```json
{
  "success": true,
  "purged_items": 1,
  "execution_time_ms": 112,
  "zone_id": "zone_981273918237"
}
```
