## Kiến trúc Tổng thể Edge Cloud

**Workers Hub** đóng vai trò là trung tâm điều phối và kiểm soát toàn bộ hạ tầng Serverless phân tán của VNTEZ. Hệ thống kết hợp mạng lưới **Cloudflare Workers** với các điểm hiện diện (PoP) tại Việt Nam và Đông Nam Á.

```
                  +-----------------------------------+
                  |          VNTEZ CONSOLE            |
                  +-----------------+-----------------+
                                    |
                    API REST / TLS 1.3 / mTLS
                                    v
+-----------------------------------+-----------------------------------+
|               CLOUDFLARE EDGE WORKERS MESH GATEWAY                   |
|                                                                       |
|  +--------------------+   +-------------------+   +----------------+  |
|  |    vntez-iam       |   |    telebot        |   |  upload/r2     |  |
|  |  (SSO & PKCE)      |   | (Alert Broadcast) |   | (Zero-Egress)  |  |
|  +---------+----------+   +---------+---------+   +--------+-------+  |
+------------|------------------------|----------------------|----------+
             |                        |                      |
             v                        v                      v
     Supabase Postgres         Telegram Bot API        Cloudflare R2
   (Session & Metadata)       (24/7 Ops Alert)       (Presigned URLs)
```

## Các Dịch vụ Cốt lõi được Quản lý

1. **Cụm Workers Serverless:** Tự động điều hướng và cân bằng tải giữa các node mạng nội địa.
2. **Telemetry vi mô:** Thu thập dữ liệu độ trễ miligiây, CPU Wall Time, và tỉ lệ lỗi HTTP 5xx.
3. **Queue Dispatcher:** Xử lý tác vụ nền bất đồng bộ và cảnh báo sự cố tức thời sang Telegram Bot.
4. **Instant Cache Purge:** Vô hiệu hóa CDN cache toàn cầu chỉ trong 120ms.
