## Mô tả Endpoint

Endpoint cung cấp dữ liệu vi mô thời gian thực đo lường chất lượng dịch vụ của từng Worker cụ thể, phục vụ việc tự động phát hiện suy giảm hiệu năng (degradation) hoặc sự cố tắc nghẽn mạng.

## Tham số Truy vấn (Query Parameters)

| Tham số | Kiểu dữ liệu | Bắt buộc | Mặc định | Mô tả |
| :--- | :--- | :--- | :--- | :--- |
| `worker_id` | `string` | Có | — | Tên định danh Worker cần truy xuất (VD: `vntez-iam-worker`). |
| `timeframe` | `string` | Không | `1h` | Khoảng thời gian phân tích: `1h`, `24h` hoặc `7d`. |

## Phản hồi Thành công (200 OK)

| Trường dữ liệu | Kiểu | Mô tả |
| :--- | :--- | :--- |
| `worker_id` | `string` | Tên Worker được giám sát. |
| `timeframe` | `string` | Khung thời gian thu thập mẫu số liệu. |
| `metrics.requests_total` | `number` | Tổng số lượng requests đã xử lý trong kỳ. |
| `metrics.avg_latency_ms` | `number` | Độ trễ trung bình tính bằng mili-giây. |
| `metrics.p99_latency_ms` | `number` | Độ trễ phân vị thứ 99 (P99) phản ánh trải nghiệm người dùng chậm nhất. |
| `metrics.cpu_time_median_ms` | `number` | Thời gian chiếm dụng CPU Wall-Time trung vị. |
| `metrics.error_5xx_rate` | `string` | Tỷ lệ phần trăm lỗi máy chủ nội bộ HTTP 5xx. |
| `health_status` | `string` | Trạng thái sức khỏe: `optimal`, `degraded`, hoặc `incident`. |
