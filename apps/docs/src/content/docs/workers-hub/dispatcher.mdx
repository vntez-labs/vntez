## Mô tả Endpoint

Kích hoạt các tác vụ xử lý hàng đợi (Queues) hoặc gửi sự kiện khẩn cấp sang Worker xử lý Telegram Bot để thông báo trực tiếp cho đội ngũ DevOps.

## Dữ liệu Yêu cầu (Request Body)

```json
{
  "target_worker": "telebot-worker",
  "event_type": "alert_incident",
  "payload": {
    "severity": "critical",
    "message": "P99 latency exceeded 200ms in Hanoi POP"
  }
}
```
