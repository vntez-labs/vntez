## Mô tả Endpoint

Kích hoạt các tác vụ xử lý hàng đợi (Cloudflare Queues) bất đồng bộ hoặc phát tín hiệu khẩn cấp sang Worker điều phối Telegram Bot để cảnh báo tức thì cho đội ngũ DevOps.

## Tham số Yêu cầu (Request Body)

| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `target_worker` | `string` | Có | Định danh Worker đích tiếp nhận tác vụ (VD: `telebot-worker`, `audit-worker`). |
| `event_type` | `string` | Có | Tên phân loại sự kiện (VD: `alert_incident`, `batch_sync`). |
| `payload` | `object` | Có | Dữ liệu chi tiết của tác vụ, bao gồm cấp độ `severity` và nội dung `message`. |

### Cấu trúc JSON Request Mẫu

```json
{
  "target_worker": "telebot-worker",
  "event_type": "alert_incident",
  "payload": {
    "severity": "critical",
    "message": "P99 latency exceeded 200ms in Hanoi POP"
  }
}
```

## Phản hồi Đã tiếp nhận (202 Accepted)

| Trường dữ liệu | Kiểu | Mô tả |
| :--- | :--- | :--- |
| `success` | `boolean` | `true` khi tác vụ đã được đẩy vào Cloudflare Queue thành công. |
| `task_id` | `string` | Mã định danh duy nhất của tác vụ nền để tra cứu trạng thái. |
| `queued_at` | `string` | Dấu thời gian ISO-8601 ghi nhận thời điểm tiếp nhận. |
| `target` | `string` | Tên Worker đích phụ trách xử lý tác vụ. |

```json
{
  "success": true,
  "task_id": "dispatch_evt_892138",
  "queued_at": "2026-11-07T08:05:00Z",
  "target": "telebot-worker"
}
```
