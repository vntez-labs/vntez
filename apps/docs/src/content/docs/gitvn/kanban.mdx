## Mô tả Endpoint

Tạo issue mới và đưa vào bảng Kanban của repository. Hỗ trợ liên kết commit thông qua cú pháp `#issue_key` trong commit message.

## Dữ liệu Yêu cầu (Request Body)

```json
{
  "repo": "vntez-core",
  "title": "Fix PKCE token verification",
  "status": "todo"
}
```
