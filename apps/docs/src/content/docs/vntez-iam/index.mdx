## Chuẩn OAuth 2.0 PKCE (RFC 7636)

VNTEZ IAM áp dụng quy trình xác thực **Proof Key for Code Exchange (PKCE)** với phương thức băm mật mã `S256`. Luồng này loại bỏ hoàn toàn nguy cơ rò rỉ mã ủy quyền (Authorization Code Interception) trên ứng dụng Web (SPA) và ứng dụng di động.

```
+-------------------+                               +-------------------+
|  Trình duyệt Web  |                               |    VNTEZ IAM      |
+---------+---------+                               +---------+---------+
          |                                                   |
          |  1. Tạo code_verifier (ngẫu nhiên 64 bytes)       |
          |  2. Tính code_challenge = SHA256(code_verifier)   |
          |                                                   |
          |  3. GET /oauth/authorize?challenge=...&method=S256|
          +-------------------------------------------------->|
          |                                                   |
          |  4. Người dùng đăng nhập & cấp quyền              |
          |<--------------------------------------------------+
          |  5. Chuyển hướng về redirect_uri với 'code'       |
          |                                                   |
          |  6. POST /oauth/token { code, code_verifier }     |
          +-------------------------------------------------->|
          |                                                   |
          |  7. IAM kiểm tra SHA256(code_verifier) == chall   |
          |<--------------------------------------------------+
          |  8. Cấp phát access_token & refresh_token         |
```
