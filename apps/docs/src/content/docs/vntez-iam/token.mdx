## Mô tả Endpoint

Sau khi người dùng cấp quyền tại trang đăng nhập VNTEZ IAM, client gửi mã `code` kèm `code_verifier` nguyên bản lên endpoint `/oauth/token` để nhận `access_token`.

## Tham số Yêu cầu (Request Parameters)

| Tham số | Kiểu | Bắt buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `grant_type` | string | Có | Giá trị cố định: `authorization_code`. |
| `code` | string | Có | Mã ủy quyền tạm thời nhận được từ query string. |
| `client_id` | string | Có | Client ID của ứng dụng đã đăng ký trên Console. |
| `code_verifier` | string | Có | Chuỗi ngẫu nhiên bí mật tạo ở bước khởi tạo PKCE. |
| `redirect_uri` | string | Có | Địa chỉ callback đã đăng ký chính xác. |
