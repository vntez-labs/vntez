## Mô tả Endpoint

Endpoint trả về cấu hình khám phá dịch vụ tự động theo chuẩn **OpenID Connect Discovery 1.0**. Các framework và thư viện xác thực như NextAuth.js, Passport.js, Auth0 SDK hoặc OIDC Client có thể tự động nạp danh sách endpoint và thuật toán mã hóa mà không cần cấu hình thủ công.
