## Cấu trúc Ma trận Quyền (Resource-Action Model)

Hệ thống phân quyền VNTEZ IAM mô hình hóa thẩm quyền dựa trên cặp **`resource:action`**:
- **Resources:** `users`, `files`, `messages`, `clients`, `roles`.
- **Actions:** `create`, `read:self`, `read:all`, `update:self`, `update:all`, `delete:self`, `delete:all`.
- **Wildcard Super-admin:** `*:*` hoặc `users:*`.
