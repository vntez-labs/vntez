## Master AI Integration Prompt

Sao chép toàn bộ nội dung prompt dưới đây và dán vào Cursor Composer, Windsurf Cascade, Claude Code hoặc GitHub Copilot để AI tự động thiết lập toàn bộ quy trình xác thực OAuth 2.0 PKCE vào dự án của bạn:

```markdown
Bạn là AI chuyên gia bảo mật và fullstack developer. Hãy tích hợp hệ thống định danh & phân quyền Single Sign-On (SSO) VNTEZ IAM với ma trận phân quyền RBAC qua giao thức chuẩn OAuth 2.0 PKCE (RFC 7636 & RFC 6749) vào dự án này theo quy trình dưới đây:

=== 1. YÊU CẦU BẮT BUỘC TRƯỚC KHI TÍCH HỢP ===
- Client ID (và Client Secret nếu là ứng dụng server bí mật) BẮT BUỘC phải được tạo và quản lý tại VNTEZ Console: https://vntez-console.vercel.app
- Khi tạo Client trên VNTEZ Console, bạn phải đăng ký đúng Redirect URI của ứng dụng (ví dụ: https://your-domain.com/auth/callback hoặc http://localhost:3000/auth/callback khi phát triển local).
- Điền Client ID đã được cấp vào biến môi trường VNTEZ_CLIENT_ID. KHÔNG ĐƯỢC để lộ Client Secret ở frontend/client.

=== 2. CỔNG XÁC THỰC VNTEZ IAM & CÁC ENDPOINT QUẢN TRỊ ===
Cổng xác thực định danh VNTEZ IAM Gateway:
- Gateway Base URL: https://vntez-iam.vercel.app
- IAM Workers Edge: https://iam.hnamhocit.workers.dev

1. Endpoint Chuyển hướng Xác thực (GET):
   URL: https://vntez-iam.vercel.app/oauth/authorize
   Tham số: client_id, redirect_uri, response_type="code", state, code_challenge (SHA-256 base64url), code_challenge_method="S256"

2. Endpoint Đổi Token (POST):
   URL: https://vntez-iam.vercel.app/oauth/token
   Payload: { grant_type: "authorization_code", code, client_id, code_verifier, redirect_uri }
   Response: { access_token, token_type: "Bearer", expires_in: 3600, scope: "openid profile email roles permissions" }

3. Endpoint Lấy Thông Tin Người Dùng & Phân Quyền (GET):
   URL: https://vntez-iam.vercel.app/oauth/userinfo
   Header: Authorization: Bearer <access_token>
   Optional Header: X-App-Id: <app_id> (hoặc query ?app_id=<app_id>)
   Response JSON:
   {
     sub: string,
     email: string,
     email_verified: boolean,
     name: string,
     avatar: string | null,
     picture: string | null,
     app_id: string | null, // ID của app đang yêu cầu (vd: "solotype" hoặc null nếu là Root Console)
     role: string, // Vai trò trong app này (vd: "admin", "member", "viewer")
     roles: string[], // Danh sách vai trò của user trong app này
     permissions: string[] // Quyền hạn tương ứng trong app này (vd: ["lessons:create", ...] hoặc ["*:*"])
   }

4. OpenID Connect Discovery:
   URL: https://vntez-iam.vercel.app/.well-known/openid-configuration

=== 3. QUY TRÌNH 4 BƯỚC THỰC HIỆN ===
Bước 1: Sinh 'code_verifier' ngẫu nhiên (43-128 ký tự) và băm SHA-256 để sinh 'code_challenge'. Sinh 'state' ngẫu nhiên (32 ký tự).
Bước 2: Chuyển hướng trình duyệt tới https://vntez-iam.vercel.app/oauth/authorize kèm các tham số trên.
Bước 3: Tại callback URL, kiểm tra 'state' khớp với session/cookie, sau đó gửi POST tới https://vntez-iam.vercel.app/oauth/token kèm 'code' và 'code_verifier'.
Bước 4: Gửi GET tới https://vntez-iam.vercel.app/oauth/userinfo với Bearer token (kèm query ?app_id=<app_id> hoặc header X-App-Id nếu là app vệ tinh) để lấy thông tin hồ sơ { sub, email, email_verified, name, avatar, picture, app_id, role, roles, permissions } tương ứng với ứng dụng yêu cầu.
```
