## Mô tả Endpoint

Lưu trạng thái đọc sách hiện tại lên Edge để bạn có thể tiếp tục đọc trên điện thoại, máy tính bảng hoặc máy tính mà không bị mất trang.

## Dữ liệu Yêu cầu (Request Body)

```json
{
  "book_id": "bk_clean_code",
  "cfi_location": "epubcfi(/6/14[chapter-2]!/4/2/10/1:24)",
  "progress_pct": 35.2
}
```
