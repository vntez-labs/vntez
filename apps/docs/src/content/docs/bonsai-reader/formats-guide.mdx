## 1. Định dạng ePub Tiêu chuẩn (.epub)

ePub là định dạng lý tưởng nhất cho Bonsai Reader:
- **Reflowable Text:** Văn bản tự động căn chỉnh lại theo kích thước cửa sổ và cỡ chữ mong muốn.
- **Mục lục TOC phân cấp:** Hỗ trợ đầy đủ các cấp chương, phần và mục lục con.
- **Font nhúng:** Tự động ưu tiên font chữ chuẩn tiếng Việt của Bonsai Reader để loại bỏ hiện tượng lỗi dấu hoặc vỡ font từ file gốc.

## 2. Định dạng PDF Kỹ thuật (.pdf)

Dành cho sách giáo trình, báo cáo nghiên cứu và tài liệu sơ đồ:
- **Chế độ vừa chiều rộng (Fit to Width):** Tự động phóng to trang tài liệu để vừa vặn với kích thước màn hình mà không cần zoom thủ công.
- **Bộ lọc làm dịu mắt:** Tự động điều chỉnh độ tương phản trang PDF khi đọc vào ban đêm để không gây chói mắt.

## 3. Tài liệu Markdown & MDX (.md, .mdx)

Bonsai Reader có thể sử dụng như một trình xem trước ghi chú Markdown cao cấp:
- Hỗ trợ cú pháp GitHub Flavored Markdown (bảng biểu, task lists, code blocks có tô màu cú pháp).
- Thích hợp cho việc đọc tài liệu dự án, bài viết kỹ thuật và ghi chú học tập.
