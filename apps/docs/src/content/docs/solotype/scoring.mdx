## Mô tả Endpoint

Ghi nhận điểm thi vào hồ sơ cá nhân và cập nhật chỉ số phần trăm cao thủ (percentile) trên toàn hệ thống.

## Dữ liệu Yêu cầu (Request Body)

```json
{
  "wpm": 112.5,
  "accuracy": 98.4,
  "language_mode": "vi_telex",
  "duration_seconds": 60
}
```
